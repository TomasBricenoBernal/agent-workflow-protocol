# Docs Index

Use `.agents/planning/docs/` for reusable repository-wide references.

Use `.agents/planning/features/` for feature-specific tracking.

Use `.agents/planning/tasks/` for task execution, handoff, and review.

Use `.agents/context/` for short operational context.

## Files

- `decision_log.md`: short reusable decisions.
- `glossary.md`: operational or domain terms.
- `token_strategy.md`: context and token usage guidance.
- `lessons/`: past mistakes and the rule that prevents each, one file per area.

## Do Not Use `.agents/planning/docs/` For

- Active task execution logs.
- Feature-specific change tracking.
- Temporary handoff notes.
